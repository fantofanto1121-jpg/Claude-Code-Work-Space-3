# Remote Pad

同じ Wi-Fi 内のスマホ・タブレット・別の PC から、Windows PC のマウスとキーボードを
リアルタイムに操作するための小さなアプリです。

- **PC 側エージェント**: Python 標準ライブラリのみ（追加の pip install 不要）。
  HTTP と WebSocket を同じポートで受け、Win32 `SendInput` で実際の入力を発生させます。
- **操作画面**: スマホのブラウザで開くだけ。トラックパッド操作と、
  PC 画面のキャプチャをタップして狙った位置をクリックする 2 つのモードがあります。
- **認証**: 起動のたびに 6 桁 PIN を生成。PIN なしでは入力も画面取得もできません。

## 入手方法

### A. exe をダウンロードする（Python 不要）

GitHub の Releases にある `remote-pad-latest` から **RemotePad.exe** を落として
ダブルクリックするだけです。Windows ランナーで PyInstaller によりビルドされ、
起動・画面取得・PIN 拒否の自動テストを通ったものだけが公開されます。

初回起動時は署名なしのため Windows Defender SmartScreen の警告が出ます。
「詳細情報」→「実行」で起動してください。

### B. ソースから動かす

`agent\start.bat` をダブルクリック、または `python agent\pc_agent.py`。

## 必要なもの

- 操作される PC: Windows 10 / 11
  （exe を使う場合は Python 不要。ソースから動かす場合は Python 3.8 以降で、
  python.org の installer の「Add python.exe to PATH」にチェック）
- 操作する端末: 同じ Wi-Fi につながったスマホなどのモダンブラウザ

## 起動

1. `agent\start.bat` をダブルクリック（または `python agent\pc_agent.py`）。
2. 初回は Windows Defender ファイアウォールのダイアログが出ます。
   **プライベートネットワーク** を許可してください。
3. ウィンドウに表示された URL（例 `http://192.168.1.23:8787/`）をスマホで開き、
   同じく表示されている 6 桁の PIN を入力します。

```
python agent\pc_agent.py --port 9000 --pin 123456
```

`--pin` を省略すると毎回ランダムな PIN になります。`--host 127.0.0.1` を指定すると
その PC 自身からのみ接続できます。exe も同じオプションを受け付けます
（`RemotePad.exe --port 9000`）。

URL に `?pin=123456` を付けて開くと PIN 入力を飛ばして接続します
（アドレスバーには残りません）。

## 操作方法

### トラックパッドモード

| 操作 | 動作 |
| --- | --- |
| 1 本指でドラッグ | カーソル移動（速度に応じた加速あり） |
| 1 本指でタップ | 左クリック |
| 2 本指でタップ | 右クリック |
| 2 本指で上下ドラッグ | スクロール |
| 3 本指でタップ | 中クリック |
| 長押し | ドラッグ固定（左ボタンを押したまま。次のタップで解除） |

下部のボタン列からも左・中・右クリック、スクロールバー、キーボードを使えます。

### 設定

上部の `設定` から次を調整できます。変更は端末に保存され、次回も引き継がれます。

| 項目 | 内容 |
| --- | --- |
| 高さ | トラックパッドの高さを 40〜100% で変更 |
| カーソル感度 | 指の移動量に対するカーソルの進み具合を 0.4〜2.5 倍 |
| スクロール感度 | 同じく 0.4〜2.5 倍 |
| スクロール方向を反転 | 2 本指とスクロールバーの向きを逆にする |
| タップでクリック | パッドを軽く触れただけでクリックしないようにする |
| 解像度 | 画面モードの取得幅を 720 / 1024 / 1280 / 1600px から選ぶ |
| ボタン列を隠す | クリック列とスクロールバーを隠し、パッドを広く使う |
| 振動 | 操作時の触覚フィードバック |

`初期設定に戻す` で全項目が既定値に戻ります。

### キーボード

`ボタン` と `入力欄` の 2 モードがあります。

**ボタン** は画面内のキーを押して打つモードです。入力欄にフォーカスしないので、
iPhone や iPad で端末のソフトキーボードがせり上がってきません。英字・数字・記号の
各レイヤー、Shift（2 回タップでロック）、Ctrl / Alt / Win（次の 1 キーに作用）、
矢印、Esc、Tab、Del、BS、Enter を備えています。`Ctrl` → `c` の順に押せば Ctrl+C です。

Shift だけが押されている場合は、キーに書かれた文字をそのまま Unicode で送ります。
VK 経由にすると PC 側のキーボード配列に依存してしまい、日本語配列では `Shift+2` が
`@` ではなく `"` になってラベルと食い違うためです。Ctrl や Alt を伴う場合だけ
VK + 修飾キーとして送ります。

**入力欄** は端末のキーボードを使うモードで、日本語の入力にはこちらを使います。
確定した文字が Unicode として送られるため、PC 側で IME を切り替える必要はありません。
選んだモードは次回も引き継がれます。

### 画面モード

PC の画面をフルカラーで表示し、触れた位置へカーソルを移動してクリックします。
長押しで右クリック、2 本指上下でスクロール。

`ライブ` に切り替えると映像のように更新され続けます。画面を 128px のタイルに分割して
CRC32 で前フレームと比較し、**変化したタイルだけを PNG にして送る**方式なので、
全画面を送り直す必要がありません。動いていない部分は 1 バイトも流れません。
下に出ている `22 fps · 37 KB/s · 1024×576` が実測値です。

タイルの転送は WebSocket のバイナリフレームで、先頭 8 バイトが
`x, y, w, h`（各 uint16）、続きが PNG 本体です。`frame_end` が届いた時点で
1 フレーム分を canvas にまとめて描画し、描き終えてから次を要求するので、
回線や PC の速度に合わせて自動的にペースが決まります。

## 構成

```
remote-pc-control/
  agent/
    pc_agent.py    HTTP + WebSocket サーバ、PIN 認証、ルーティング
    win_input.py   SendInput による入力、GDI による画面キャプチャ、PNG エンコーダ
    start.bat      Windows 用ランチャ
  web/
    index.html     操作画面
    style.css      配色・レイアウト（ダーク／ライト自動切替）
    app.js         ジェスチャ処理と WebSocket クライアント
```

### WebSocket プロトコル（`ws://<host>:<port>/ws`、JSON 1 行 1 メッセージ）

| 送信 | 内容 |
| --- | --- |
| `{"t":"auth","pin":"123456"}` | 最初に必須。失敗すると切断 |
| `{"t":"rel","dx":5,"dy":-3}` | 相対移動（ピクセル） |
| `{"t":"abs","x":0.5,"y":0.3}` | 仮想デスクトップ全体を 0〜1 に正規化した絶対移動 |
| `{"t":"btn","b":"left","s":"click"}` | `b`: left / middle / right、`s`: down / up / click |
| `{"t":"scroll","dy":2,"dx":0}` | ホイール（1 = 1 ノッチ） |
| `{"t":"key","k":"c","mods":["ctrl"]}` | 単キー＋修飾キー |
| `{"t":"text","s":"こんにちは"}` | Unicode 文字列をそのまま入力（IME 不要） |
| `{"t":"ping","id":123}` | 応答 `{"t":"pong","id":123}` で遅延計測 |
| `{"t":"frame","w":1024,"full":false}` | 画面を 1 フレーム要求。`full` で全タイル再送 |

応答はタイルのバイナリフレーム（`x,y,w,h` の uint16 ×4 + PNG）が必要数続き、
最後に `{"t":"frame_end","w":1024,"h":576,"n":4,"bytes":3072,"full":false}` が届きます。

静止画 1 枚だけ欲しい場合は `GET /api/shot?pin=<PIN>&w=<横幅>` で PNG が返ります。

## セキュリティ上の注意

- このエージェントは**接続した相手に PC の操作権限をそのまま渡します**。
  信頼できる自分の端末からのみ使ってください。
- 通信は暗号化されていません。LAN 内での利用を前提にしています。
  外出先から使いたい場合は VPN か Cloudflare Tunnel 等の経路を別途用意してください
  （PIN だけをインターネットに公開しないこと）。
- PIN は起動ごとに変わります。固定したい場合のみ `--pin` を使ってください。
- 使い終わったらエージェントのウィンドウを閉じる（Ctrl+C）だけで完全に止まります。
