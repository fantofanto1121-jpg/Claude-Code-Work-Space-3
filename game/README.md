# スライム・スリング — はじまりの森

添付イラストをもとにした、引っ張って弾く 2D アクションゲームです。
ブラウザだけで動きます（インストール不要・通信なし・画像素材ゼロ）。

グラフィックはすべて Canvas 2D による手続き的な描画です。空・雲海・連なる山脈・
浮遊する城・滝・草地の崖・キャラクターまで、1 枚も画像ファイルを使っていません。

---

## 遊びかた

`game/index.html` をブラウザで開くだけです。

```
# どちらでも可
open game/index.html                 # macOS
xdg-open game/index.html             # Linux
python3 -m http.server 8000          # ブラウザで http://localhost:8000/game/
```

### 操作

| 操作 | 内容 |
|------|------|
| 画面をドラッグ → はなす | スライムを引っ張って発射（引いた向きの反対に飛ぶ） |
| 中央の大きいボタン / スペースキー | 前回と同じ向きに弱めに発射 |
| スペシャル（左のボタン）/ E キー | ゲージが満タンのとき発動。次の一撃が強化され、衝撃波で周囲にもダメージ |
| ポーション（右のボタン）/ Q キー | ハートを 2 つ回復（残数あり） |
| やり直す / R キー | 今のステージを最初から |

発射できるのは地面で静止しているときだけです。勢いがついた状態で敵にぶつかると
ダメージを与え、止まっている状態で敵に触れるとこちらがダメージを受けます。

### ルール

- 各ステージの モンスターを すべて倒すとクリア（右上のカウンタ）。
- ハートが 0 になるとゲームオーバー。谷に落ちてもハートを 1 つ失います。
- 敵を倒すと経験値が入り、レベルアップでハートが全回復します。偶数レベルで最大ハートが 1 増えます。
- ステージは 3 つ（1-1 はじまりの森 / 1-2 たきのかけ橋 / 1-3 そらの城門）。1-3 には王冠のボスがいます。

## ファイル構成

```
game/
├── index.html        画面と HUD（ステータス・クエスト・ミニマップ・操作ボタン）
├── css/style.css     HUD のスタイル。すべて cqw 指定で画面サイズに比例して拡大縮小
└── js/
    ├── art.js        描画エンジン（背景・地形・キャラクター・エフェクト）
    ├── stages.js     ステージ定義（足場・敵の配置・装飾）
    └── game.js       本体（物理・入力・敵の行動・HUD 連携・効果音）
```

### 画面の作り

| レイヤー | 視差 | 中身 |
|----------|------|------|
| 遠景 | 0.18 | 空のグラデーション、雲、三重の山脈、浮遊する城、雲海 |
| 中景 | 0.45 | 浮島群、石橋、滝 |
| プレイ面 | 1.00 | 足場の岩と草地、旗・柵・木箱・ランタンなどの装飾 |
| 前景 | 1.15 | ぼかした草花 |

遠景・中景・プレイ面はステージ読み込み時にオフスクリーンへ一度だけ描き、
毎フレームは転送のみ。滝・キャラクター・エフェクトだけを都度描いています。

### 調整したいとき

- 難易度・敵の強さ: `js/game.js` の `ENEMY_DEF`
- 飛距離や重力: `js/game.js` 先頭の `GRAVITY` / `LAUNCH_MIN` / `LAUNCH_MAX` / `MAX_PULL`
- ステージの地形と敵の配置: `js/stages.js`
- 配色や地形の描き方: `js/art.js`

`index.html?debug` で開くと `window.__game` から内部状態（`G`・`loadStage`）を触れます。

## 動作環境

Chrome / Edge / Safari / Firefox の最近のバージョン。スマートフォンでも遊べます
（画面は常に 3:2 の比率を保ち、HUD も一緒に拡大縮小します）。

音は WebAudio による簡単な効果音のみで、音声ファイルはありません。右上の「音 ON / OFF」で切り替えます。

この `game/` フォルダは独立していて、リポジトリ内の掲示板アプリ（FastAPI）とは
依存関係がありません。どちらか一方だけを動かせます。
