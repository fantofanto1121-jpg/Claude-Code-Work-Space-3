> **調査日: 2026年10月16日**

## 結論

| 項目 | 金額 |
|------|------|
| 初期費用 | **0円** |
| 月額費用（独自ドメインなし） | **0円** |
| 月額費用（独自ドメインあり） | **年 1,000〜2,000円程度**（ドメイン代のみ） |

小規模な個人運営（1日あたり数百アクセス程度）であれば、無料枠に収まる見込みです。

## 1. Render（アプリの実行） — 無料プラン

出典: [Deploy for Free – Render Docs](https://docs.render.com/free) / [Render Pricing 2026](https://temps.sh/blog/render-pricing-2026)

| 確認項目 | 内容 | 確認状況 |
|----------|------|----------|
| 無料枠の内容 | 月 **750 インスタンス時間**（ユーザー／チームあたり） | 確認済み |
| スリープ | **15分間アクセスが無いと停止**。次のアクセスで自動復帰 | 確認済み |
| 復帰にかかる時間 | 初回アクセスに**約1分**の待ち時間 | 確認済み |
| 枠を使い切ったら | その月は無料サービスが**停止**。翌月1日に復活 | 確認済み |
| 永続ディスク | **使えない**（再起動でファイルが消える） | 確認済み |
| Shell / SSH | **使えない**（有料プラン専用）。DBの初期化は自分のPCから行う | 確認済み |
| HTTPS | 標準で付く（`*.onrender.com`） | 確認済み |
| 商用利用 | — | **未確認**（公式の利用規約で要確認） |
| クレジットカード登録 | — | **未確認**（2026年時点の情報が見つかりませんでした。登録画面で確認してください） |
| 日本からの利用 | シンガポールリージョンが利用可。日本から比較的近い | 確認済み |

### スリープへの対処

- 無料のまま使う場合、**最初の訪問者だけ約1分待つ**ことになります。個人の掲示板なら実用上は許容範囲です。
- 外部の監視サービスで定期的にアクセスして起こし続ける方法がありますが、
  750時間（= 約31日分）を使い切ると月末まで停止するため、**常時稼働させると枠を超えます**。
  アクセスの多い時間帯だけ起こす、などの調整が必要です。
- 完全に解消したい場合は有料プラン（月 $7 程度）です。

### アップロードしたファイルが消える点

永続ディスクが無いため、**画像アップロード機能を今のまま追加しても、再起動で画像が消えます**。
追加する場合は Cloudflare R2 や Backblaze B2 など、外部のストレージが別途必要です
（本プロジェクトで画像アップロードを初期機能に入れていないのは、この理由もあります）。

## 2. Neon（データベース） — 無料プラン

出典: [Neon Pricing](https://neon.com/pricing) / [Neon Pricing in 2026](https://www.jetadmin.io/blog/neon-pricing/) / [releases.sh digest](https://releases.sh/collections/serverless-postgres/digest/2026-09-28)

| 確認項目 | 内容 | 確認状況 |
|----------|------|----------|
| ストレージ | **0.5GB〜1GB／プロジェクト** | **情報が割れています**。2026年9月に 0.5GB → 1GB へ増量との報告がありますが、一次情報を確認できませんでした。公式ページで要確認 |
| 計算リソース | **100 CU時間／プロジェクト／月** | 確認済み |
| 自動停止 | **5分間アクセスが無いと停止**。次のクエリで**自動復帰**（手動操作は不要） | 確認済み |
| 復帰にかかる時間 | 数百ミリ秒〜数秒 | 確認済み |
| プロジェクト数 | 100まで | 確認済み |
| 転送量 | 5GB／月 | 確認済み（出典は二次情報） |
| バックアップ保持 | 6時間（履歴ウィンドウ） | 確認済み（出典は二次情報） |
| クレジットカード登録 | **不要** | 確認済み |
| 商用利用 | — | **未確認**（公式の利用規約で要確認） |
| 無料枠を超えたら | 自動課金はされず、制限がかかる方式と理解していますが | **未確認**。必ず公式で確認してください |

### 0.5GB はどれくらい持つか（概算）

1投稿を平均 500 バイトとすると、索引込みでおよそ 1KB 前後。
**50万投稿で約 500MB** の計算になります。個人運営の掲示板では、当面は十分です。

### 重要: 自動バックアップの保持は6時間

Neon の履歴ウィンドウは短いため、**自分でバックアップを取る運用が必須**です。
[docs/BACKUP.md](BACKUP.md) の手順を、最低でも週1回実行してください。

## 3. Resend（メール送信） — 無料プラン・任意

出典: [Resend Pricing](https://www.resend.com/pricing.md)

| 確認項目 | 内容 | 確認状況 |
|----------|------|----------|
| 送信数 | **月 3,000通 / 1日 100通** | 確認済み |
| 独自ドメイン | 1つ | 確認済み |
| 上限に達したら | 送信が停止。自動課金はされない | 確認済み |
| データ保持 | 30日 | 情報が割れています（1日とする記述もあり）。要確認 |

**設定しなくてもアプリは動きます。** 未設定の場合、パスワード再設定リンクは
サーバーのログに出力されます（Render のダッシュボードから閲覧可）。

ただし公開運営するなら、設定を強く推奨します。未設定だと、
利用者が自分でパスワードを再設定できません。

> **独自ドメインについて**: Resend で送信元アドレスを使うにはドメイン認証（SPF / DKIM）が
> 必要です。独自ドメインを持たない場合、メール機能は実質使えません。

## 4. ドメイン（任意）

| 項目 | 目安 |
|------|------|
| `.com` | 年 1,500〜2,000円 |
| `.net` | 年 1,500〜2,000円 |
| `.jp` | 年 3,000〜4,000円 |

**独自ドメインは必須ではありません。** `https://〇〇.onrender.com` のままでも
会員登録・投稿・HTTPS すべて問題なく動作します。

必要になるのは次の場合です。
- メール送信（Resend）を使いたい
- サービスとして見栄えを良くしたい
- 将来ホスティング先を変えてもURLを保ちたい

## 5. 将来かかる可能性のある費用

| きっかけ | 費用の目安 | 対策 |
|----------|-----------|------|
| アクセスが増えて Render 無料枠（750時間）を超える | 月 $7〜 | 有料プランへ |
| スリープを無くしたい | 月 $7〜 | 同上 |
| DBが 0.5GB を超える | 月 $5〜（Neon 有料） | 古いログの削除、`rate_limit_hits` の定期掃除 |
| 画像アップロードを追加 | 月 0〜数百円（Cloudflare R2 等） | 外部ストレージが必須 |
| メールを月3,000通以上送る | 月 $20〜 | 通知メールを減らす設計に |
| 独自ドメイン | 年 1,500円〜 | 任意 |

### 費用を抑えるコツ

1. `rate_limit_hits` テーブルは放置すると太ります。`app/ratelimit.py` の `prune()` を
   定期実行するか、手動で古い行を削除してください。
2. 画像アップロードは慎重に。容量と転送量を一気に消費します。
3. Render は「1サービスにつき1リージョン」です。無駄にサービスを増やさないこと。
